# herdr-ticket-flow

Mods for the [Herdr](https://herdr.dev) desktop app that take a ticket from your
tracker to a merged pull request: pick a ticket, get a worktree with a coding
agent in it, and drive the PR (draft, CI, review comments, ready, merge, clean
up) from Herdr's sidebar.

Work in progress: being extracted from a personal dotfiles setup. The plan and
progress are tracked in this repo's issues.
